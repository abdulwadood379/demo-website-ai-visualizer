Paging, In Short

Memory is cut into equal boxes called frames. A process's pages fit into any free frame — they don't need to sit together.

An address splits into a page number (looked up) and an offset (carried over unchanged).

Page size = frame size, so the offset transfers directly.

TLB caches recent lookups to skip the table walk.

A page fault costs a disk access.
