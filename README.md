# PPT AI Visualizer

**AI-Powered PPT Explainer & Visualizer — UI/UX Prototype**

This project is a **frontend UI/UX prototype** for an AI-powered platform designed to help users understand PowerPoint presentations through explanations and visualizations.

## About

The concept is to allow users to upload a PowerPoint presentation and, in the future, use AI to analyze the content, explain the topics, and generate visual explanatory scenes.

**Currently, this project contains only the frontend UI/UX.**

The buttons and AI features are **not functional yet**.

## Current Status

* 🎨 UI/UX design completed
* 🖥️ Frontend interface developed
* 📄 Presentation upload interface designed
* 🤖 AI functionality not implemented yet
* 🔗 Backend not connected yet
* ⚙️ Buttons and interactive features are currently non-functional

## Technologies

* HTML
* CSS
* JavaScript

## Future Development

The planned functionality includes:

* PowerPoint file upload
* AI-based presentation analysis
* AI-generated explanations
* Visual and explanatory scene generation
* Interactive visualizations
* Backend and AI integration

## Purpose

This prototype demonstrates the **planned user interface and user experience** of an AI-powered presentation explanation and visualization platform.
